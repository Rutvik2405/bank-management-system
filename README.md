# Bank Management System

A fully functional, secure web-based Bank Management System built with Python, Flask, SQLAlchemy, and SQLite. This is an educational project demonstrating real-world web development, security, and database transactions.

## Features

- **Authentication System**: Secure registration and login with hashed passwords.
- **Role-Based Access**: Separate interfaces and permissions for Customers and Admins.
- **Customer Dashboard**: View account details, current balance, and recent transactions.
- **Banking Operations**: 
  - Deposit Money
  - Withdraw Money (with insufficient balance checks)
  - Transfer Money (Atomic database transactions to prevent partial failures)
- **Transaction History**: View, sort, and filter transaction history.
- **Admin Dashboard**: 
  - View overall bank statistics (Total customers, accounts, bank balance, transaction volumes).
  - Manage customers and search by name/email/account.
  - Block or Activate customer accounts.
  - View all bank transactions.
- **Security**: SQL Injection prevention (via SQLAlchemy), input validation, no direct balance modifications allowed, secure password storage.

## Technology Stack

- **Backend**: Python 3.11+, Flask
- **Database**: SQLite, SQLAlchemy (ORM)
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5, Jinja2
- **Security**: Werkzeug (Password Hashing)
- **Testing**: Pytest

## Installation

1. **Clone the repository** (if applicable) or navigate to the project folder:
   ```bash
   cd "Bank Management System"
   ```

2. **Set up a Virtual Environment**:
   ```bash
   python -m venv venv
   ```
   *Activate it:*
   - Windows: `venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Environment Variables**:
   Copy `.env.example` to `.env` (or configure your environment):
   ```bash
   cp .env.example .env
   ```
   *(Make sure to change `SECRET_KEY` in production)*

5. **Initialize the Database**:
   Run the initialization script to create tables and demo users:
   ```bash
   python init_db.py
   ```

## Running the Application

Start the Flask development server:
```bash
python app.py
```
Visit `http://127.0.0.1:5000` in your web browser.

## API Routes

- `/` - Landing Page
- `/login` - User login
- `/register` - Customer registration
- `/logout` - Logout
- `/dashboard` - Customer dashboard
- `/account` - View account details
- `/profile` - Edit profile information
- `/deposit` - Deposit money
- `/withdraw` - Withdraw money
- `/transfer` - Transfer money
- `/transactions` - View customer transaction history
- `/admin/dashboard` - Admin statistics dashboard
- `/admin/customers` - View/search all customers
- `/admin/transactions` - View all bank transactions
- `/admin/account/<id>/block` - Block an account
- `/admin/account/<id>/activate` - Activate an account
